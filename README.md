# ClickMineMedia

Next-generation digital media and creator growth website built with Next.js (App Router), TypeScript, and custom modern styling.

## 🚀 Features

- **Next.js 14 App Router**: Clean structure with `app/layout.tsx` and `app/page.tsx`.
- **TypeScript**: Full type safety with strict compiler configuration (`tsconfig.json`).
- **Luxury Dark Aesthetic**: Obsidian black palette, glassmorphism, glowing micro-animations, and responsive layout.
- **Interactive Growth Estimator**: Dynamic slider for estimating impressions, creator matchings, and ROAS.
- **Conversion-Focused**: Case studies bento grid, capability showcase, and client strategy inquiry form.

## 📁 Project Structure

```text
cmm/
├── app/
│   ├── components/
│   │   ├── Navbar.tsx      # Sticky glassmorphism header with mobile menu
│   │   └── Footer.tsx      # Comprehensive agency footer & newsletter
│   ├── globals.css         # Dark theme design system & animations
│   ├── layout.tsx          # Root layout with SEO meta tags
│   └── page.tsx            # Main landing page & interactive sections
├── next.config.mjs         # Next.js configuration
├── package.json            # Scripts & dependencies
├── tsconfig.json           # TypeScript configuration
└── .gitignore              # Standard Next.js gitignore
```

## 🛠️ Getting Started

### 1. Install Node.js
If you don't have Node.js installed on your machine yet, install it via [Homebrew](https://brew.sh) or [nodejs.org](https://nodejs.org):

```bash
brew install node
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.
